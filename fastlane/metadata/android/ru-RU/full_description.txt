SparkleDNS шифрует каждый DNS-запрос на устройстве с помощью DNS-over-HTTPS (RFC 8484) и HTTP/3. VPN Android используется только локально: в туннель попадают лишь DNS-запросы, весь остальной трафик идёт обычным путём, поэтому скорость и батарея не страдают.

<b>Серверы</b>
<ul>
<li>SkySparkle (по умолчанию) с HTTP/3, работает у разработчика</li>
<li>Cloudflare, Google, Quad9, AdGuard, Mullvad</li>
<li>Любой свой DoH-сервер, с bootstrap IP и HTTP/3 по желанию</li>
</ul>

<b>Возможности</b>
<ul>
<li>Подключение одним касанием, плитка в шторке, поддержка постоянного VPN</li>
<li>Монитор: каждый запрос со статусом и задержкой, фильтры, поиск и блокировка одним касанием</li>
<li>Правила для приложений: группы по категориям, выбранные приложения идут мимо SparkleDNS</li>
<li>Блоклисты: свои домены и списки hosts, доменов, AdBlock и dnsmasq по ссылке, HaGeZi Pro++ и TIF в одно касание. Поддомены блокируются тоже, изменения применяются сразу</li>
<li>Локальный DNS-кэш с учётом TTL</li>
<li>Проверка сервера с протоколом (h3 или h2) и задержкой</li>
</ul>

<b>Приватность</b>
Никакой аналитики, рекламы и сервисов Google Play. Журнал запросов хранится только в памяти и никуда не отправляется. DNS-запросы уходят на выбранный вами сервер. Сервер SkySparkle по умолчанию работает у разработчика по этой политике конфиденциальности: https://skysparkle.cc/privacy?lang=en

<b>Разрешения</b>
<ul>
<li>VPN: локальный туннель только для DNS, ничего не уходит на удалённый VPN</li>
<li>Уведомления: статус подключения и кнопка «Отключить»</li>
<li>Состояние сети: нужно движку HTTP/3 Android и для проверки частного DNS</li>
<li>Установленные приложения (только ярлыки лаунчера): для правил по приложениям</li>
</ul>

Для HTTP/3 нужен Android 14 или новее, на более старых используется HTTP/2. Если в настройках Android «Частный DNS» задан конкретным хостом, Android отправляет DNS туда; SparkleDNS предупреждает об этом.

<p>Защитите свои DNS-запросы с помощью зашифрованного DNS-over-HTTPS, а остальной интернет-трафик пусть идёт по обычному соединению. SparkleDNS даёт контроль над DNS, не пропуская всё устройство через VPN-сервер.</p>

<li>Отправляйте DNS-запросы на выбранный DoH-сервер по RFC 8484.</li>

<li>Добавляйте свои правила для доменов или блок-листы по URL, включая пресеты HaGeZi Pro++ и TIF.</li>
<li>Разрешайте выбранным приложениям обходить DNS-туннель.</li>

</ul>

<p>SparkleDNS создаёт локальный VPN-туннель, который перехватывает только DNS-трафик. DNS-запросы уходят на выбранный DoH-сервер, всё остальное идёт по обычному соединению. Если сменить сервер во время подключения, туннель перезапустится автоматически. Никакой аналитики и сервисов Google Play.</p>
